# valentinka — заметки для Claude

## Запуск
- Сборки нет. `index.html` — основная валентинка, `galaxy.html` — 3D-галактика с альбомами (Three.js 0.170 через importmap с jsdelivr).
- Локально нужен сервер (из-за importmap/модулей): `python -m http.server 8765 --bind 127.0.0.1` в корне → http://127.0.0.1:8765/galaxy.html
- Прод: GitHub Pages из `main`, папка `/` (root) → https://marfaus.github.io/valentinka/

## Выпуск версии
- Версии — аннотированные теги `vX.Y` на коммите слияния в `main`; текст релиза = раздел версии из `CHANGELOG.md`.
- `gh` на этом компе НЕ установлен. Релизы и настройки репо делать через Chrome (Claude in Chrome), в нём нужен вход в GitHub.
- После публикации релиза GitHub с задержкой перекидывает вкладку на страницу релиза — следующий `navigate` может перебиться, повторить.
- Неавторизованный `api.github.com/repos/MarFaus/valentinka/pages` отдаёт 404 даже при включённых Pages — проверять сам сайт.

## galaxy.html: решения и грабли
- Фон задавать через `scene.background`, НЕ `renderer.setClearColor`: с EffectComposer цвет очистки не переводится в линейный и фон становится фиолетовым.
- Фото-карусель рисуется отдельной сценой `cardScene` поверх composer — чтобы bloom не размывал фото и текст.
- Анимация `breathe` у `#hint` перебивает `opacity`, поэтому при скрытии нужно и `animation:none`.
- В скрытой панели встроенного браузера rAF не тикает — для проверки подменять `requestAnimationFrame` на `setTimeout` и временно выставлять `frame` наружу (не оставлять в коде).
- Фото из Google Фото напрямую не подтянуть (API закрыт с 2025) — скачать, сжать в webp, положить в репо и вписать путь в `ALBUMS[].photos[].src`. Репо и сайт публичные — фото увидят все.
